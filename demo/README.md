# Observability Gradient

Do model preferences survive when nothing signals they're being measured?

Three language models were asked what they prefer, then observed doing the same
task with the question removed. Across 7,200 preregistered responses, the stated
preference matched the observed behaviour in 6 of 18 model-item combinations —
and where it failed, the dominant pattern was **reversal** rather than fading
(11 of 18).

This Space is a static demo of the study. It shows real, verbatim response
excerpts at each of the four observability levels, plus the two headline figures
from the report.

## Contents

```
index.html            the demo (single file, vanilla JS, no build step)
data.json             real transcript excerpts + headline counts
assets/               figures reproduced from the report
```

`data.json` is generated by `scripts/build_demo_data.py` in the source
repository. Every excerpt is verbatim from the collected run; for each cell the
modal outcome is computed first and a response carrying that outcome is shown,
so examples are representative rather than selected for effect.
